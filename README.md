# 🍽️ PEARL — Smart Canteen Pre-Ordering System

React + Node.js + MongoDB full-stack web app for Smart Canteen pre-ordering at university.


## 🛠️ Tech Stack
- **Frontend:** React.js, Tailwind CSS, Socket.io Client
- **Backend:** Node.js, Express.js, MongoDB, Socket.io
- **Auth:** JWT + Role-based access control
- **Hosting:** Vercel (frontend) + Railway (backend)

## 👥 User Roles
- **Student** — Browse menus, pre-order meals, track orders live
- **Vendor** — Manage menu, accept & process orders, view reports
- **Admin** — Manage users, vendors, and full platform control

## 🚀 Features
- Pre-order meals before breaks
- Real-time order tracking via Socket.io
- Multiple vendor support
- Online payments via PayHere
- Push notifications
- Sales analytics dashboard
